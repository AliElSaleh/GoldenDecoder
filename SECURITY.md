# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.x.x | :x:                |

### Supported Architectures
- x64
- arm64

### Supported Platforms
- Windows 10 and above
- Linux (using X11 display server)
- macOS 11 (Big Sur) and above
